# Java Practice Hub ☕💻

A learning space inspired by HackerRank 😎.

This repo is designed to help learners practice:
- Java fundamentals ☕
- Problem solving 🧠
- OOP & Collections 📦
- Streams & Lambdas 🌊
- OCP-style Java questions 😭

---

## 🚀 How It Works

1. Create your own branch!
2. Complete an exercise
3. Run the tests
4. Push your solution!!

---

## 🛠 Tech Stack

- Java 17
- Maven
- JUnit 5
- GitLab CI/CD

---

## ▶ Run Tests

```bash
mvn test
```
If everything passes:
BUILD SUCCESS

---

## 📂 Project Structure
```
src/main/java  → Exercises
src/test/java  → Tests
challenges/    → Instructions
.../solutions/ → Example solutions
```
Happy coding & try not to use intellisense as much ✌️😉
